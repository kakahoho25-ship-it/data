# 디아의 하브루타 독서토론

PRD를 바탕으로 만든 반응형 단일 페이지 홍보 사이트입니다. 별도 빌드 과정 없이 `dist/index.html`을 바로 배포합니다.

## 자주 바뀌는 정보 수정

`dist/site-config.js`에서 아래 항목만 수정하면 됩니다.

- 모집 상태
- 일정
- 선정 도서
- 비용 안내
- 수업 참여 희망 등록 네이버 폼 주소
- 기관·모임 출강 문의 네이버 폼 주소

폼 주소가 준비되지 않았을 때는 빈 문자열로 두세요. 버튼이 외부 링크로 작동하지 않고 `폼 준비 중` 상태로 표시됩니다.

## 자료 추가 전 확인

- 최종 로고는 원본 파일을 받은 뒤 적용합니다.
- 수업 사진은 얼굴과 활동지의 이름·개인 답변이 보이지 않는 것만 사용합니다.
- 현재의 수업 사례는 의왕시 배달강좌를 통해 진행한 과거 8주 과정이며, 신규 4주 과정과 구분합니다.
